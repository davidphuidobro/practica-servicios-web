Análisis de Proveedores de Servicios Web

David Pérez Huidobro
Plataformas para despliegue y alojamiento de aplicaciones web: características, ventajas, desventajas y el tipo de proyectos ideal para cada una.
Netlify Jamstack / Hosting Estático + Serverless
Ideal: Frontend, páginas estáticas (HTML, CSS, JS) y frameworks modernos (React, Vue, etc.)
Ventajas: Despliegue inmediato arrastrando carpetas o desde Git. SSL gratis. Extremadamente rápido.
Desventaja: No soporta backend tradicional persistente (Node.js continuo o bases de datos integradas).
Modelo de coste: Gratuito (Plan Starter con 100 GB de ancho de banda).
Tipo de servicio: Jamstack / Hosting Estático y Serverless.
Render Cloud PaaS
Ideal: Aplicaciones web completas (Full-stack) que requieren servidor activo y base de datos.
Ventajas: Soporta Backend (Node.js, Python, PHP, Docker) y bases de datos (PostgreSQL). Muy fácil integración con GitHub.
Desventaja: Los servicios gratuitos "se duermen" tras 15 minutos de inactividad, tardan en reactivarse.
Modelo de coste: Gratuito (servicios web y bases de datos con recursos limitados).
Tipo de servicio: Cloud PaaS (Plataforma como Servicio).
GitHub Pages Hosting Estático integrado
Ideal: Portafolios, documentación de proyectos, aplicaciones sencillas del lado del cliente.
Ventajas: Integración nativa total con el control de versiones de GitHub. Sin costes ocultos.
Desventaja: Solo permite contenido estático. No procesa código de servidor (no PHP, no Node.js).
Modelo de coste: Gratuito (para repositorios públicos).
Tipo de servicio: Hosting Estático integrado en repositorio.
Hostinger Hosting Compartido Tradicional
Ideal: Sitios web tradicionales, WordPress, e-commerce pequeños y aplicaciones PHP clásicas.
Ventajas: Incluye panel de control clásico (cPanel), gestión de correo corporativo y excelente soporte para PHP/MySQL.
Desventaja: No tiene plan gratuito de prueba. Despliegue más manual (FTP o instaladores automáticos).
Modelo de coste: De pago (suscripciones mensuales económicas).
Tipo de servicio: Hosting Compartido Tradicional.
